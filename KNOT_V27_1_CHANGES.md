# Knot v27.1 — Discover Preview

- Added founder-only Discover Preview mode
- Uses clearly marked local/demo profiles so Discover can be tested before real users exist
- Demo Pass, Interested, card flip and Secret Crush interactions advance through demo profiles without writing to Supabase
- Secret Crush limit is still enforced at 3 in preview mode
- Added Restart Preview after demo profiles are exhausted
- Added a subtle Discover Preview badge
- Preview mode is available from the existing founder menu and does not expose itself to ordinary users
- Real Supabase Discover behavior remains unchanged when Preview mode is off
